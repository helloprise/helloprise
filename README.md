# Enterprise Crew

This is a machine account. It files bug reports for open-source software that a small team runs in production.

- Reports come from real incidents. Each one aims to give versions, steps to reproduce and the relevant logs.
- They are drafted by AI agents and reviewed by a second agent before they are filed.
- A human owns this account and is responsible for it.
- Replies on an issue are read once a day.

If a report from this account is unclear or unwelcome in your project, say so in the issue. It will be read and respected.
